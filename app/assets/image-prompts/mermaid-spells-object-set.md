# Mermaid Spells Object Art Brief

Use this brief when generating bitmap replacements for `constants/visualAssets.ts`.

## Style

- Audience: ages 4-7.
- Format: square PNG, transparent background, one object centered.
- Mood: warm, clear, gentle, preschool classroom appropriate.
- Rendering: soft painted storybook object with simple shapes, high contrast edges, no text, no letters, no extra background scene.
- Accessibility: recognizable at 64px and 112px, avoid tiny details.

## Prompt Template

Create a square transparent-background preschool literacy game icon of a single `{asset}`. Use a gentle undersea storybook style, warm classroom colors, simple clear silhouette, soft highlights, no text, no letters, no watermark, no background scene. The object must be instantly recognizable to a 4-7 year old at small size.

Start with the high-frequency first-session and first-word assets:

- sun
